# Snatcher — русский перевод (PlayStation, uncensored)

**Версия перевода 0.1**, 2026

*Snatcher* — киберпанк-адвенчура Хидэо Кодзимы. В Нео-Кобе Гиллиан Сид,
детектив без памяти о прошлом, поступает в отряд ДЖАНКЕР охотиться на
снатчеров — машин, которые убивают людей и занимают их место.

Это русский перевод японской версии для PlayStation (*Snatcher*, Konami,
1996, SLPS-00154) в варианте **uncensored**: с картинками, которые
PlayStation-версия затемняет или закрывает мозаикой. Перевод сделан на
основе английского фанперевода pepa ([pepasjc/snatcher-translated](https://github.com/pepasjc/snatcher-translated),
v1.5.1) со сверкой по японскому оригиналу; этот репозиторий — его форк,
и вся техническая часть (вставка текста, субтитры к озвучке, перерисовка
графики) взята оттуда.

## Что переведено

Игра целиком, от New Game до финала.

- Весь сценарий всех 39 сцен: диалоги, описания, база данных Гауди, звонки
  по видеофону, отладочное меню. Текст не урезан под японские окна: длинная
  реплика продолжается на следующей странице окна.
- Субтитры к озвученным сценам, от вступительного рассказа до финала, по
  времени озвучки. Слева в окне — портрет говорящего, имя — его цветом.
- Меню действий, предметы, места, таблички с именами говорящих.
- Картинки с текстом: тринадцать страниц записок Гибсона, его записка
  «Обыщи дом!», карточки видеофона, шуточные картинки телефонного
  справочника, красный дисклеймер после New Game и он же во вступительном
  ролике, надпись на чертеже снатчера во вступлении.
- Перед логотипом Konami — карточка перевода и короткое предупреждение о
  том, что перевод сделан с помощью ИИ.

Имена — по звучанию, как их произносят актёры озвучки: Гиллиан Сид,
Рэндам Хаджайл, доктор Мэднар, Кэтрин Гибсон, Гауди. Японские имена — по
системе Поливанова. Все решения по терминам — в [ru/GLOSSARY.md](ru/GLOSSARY.md).

**Остаётся латиницей:**

- Экранная клавиатура и всё, что на ней набирается: имена для поиска в базе
  Гауди, пароль Наполеона (OVER, REIGN), название больницы. Клавиатура в
  игре латинская; в подсказках латинские слова поясняются по-русски
  («Революция - OVER (окончена)»).
- Оригинальные английские надписи Konami: NOW LOADING, «50 years later»,
  посвящение во вступлении, OPTION MENU и меню настроек.
- Титры во вступлении (имена актёров и создателей).

## Uncensored

PlayStation-порт цензурирует три картинки, но оригиналы остались на диске.
Этот патч их возвращает:

- **Тело на руинах завода** (Акт 1): в PlayStation-версии картинка
  обесцвечена и затемнена; возвращается полноцветный оригинал, который на
  диске есть, но игрой не загружается.
- **Тело с личинками в больнице «Куин»**: в PlayStation-версии закрыто
  мозаикой; возвращается чистая версия с того же диска.
- **Снатчер в раздевалке** (Изабелла/Лиза): берётся из версии для Sega
  Saturn, где картинка не цензурирована, и сжимается до ширины
  PlayStation-версии, как это сделала Konami.

Сцена с собакой, падающей из окна, остаётся такой, как в PlayStation-версии.

## Как наложить патч

Нужен собственный образ *Snatcher (Japan)* для PlayStation в формате
BIN/CUE, совпадающий с записью redump.org:

```
Size   573702192
CRC32  d5475fac
MD5    b6b825a8c91fd9879553c8a4e6e791c8
SHA1   e6cd330feb594b3951089da866db1a400f0173f6
```

Наложите патч из архива `Snatcher-PS1-RU-v0.1.zip` программой xdelta3,
Delta Patcher (Windows), MultiPatch (macOS) или любой другой оболочкой
xdelta:

```
xdelta3 -d -s "Snatcher (Japan).bin" "Snatcher (Japan) [T-Ru v0.1].xdelta" "Snatcher (Japan) [T-Ru v0.1].bin"
```

Рядом с полученным `.bin` положите `.cue` из архива. Новый образ больше
исходного — перенесённые данные дописаны в конец; так и должно быть.
Контрольная сумма результата указана в README.txt внутри архива.

Сохранения с карты памяти от оригинальной игры и от английского перевода
подходят.

## Как устроен перевод

Игра хранит текст двухбайтовыми номерами символов своего шрифта.
Английский перевод pepa рисует в неиспользуемых ячейках шрифта (кандзи,
которые после перевода больше нигде не нужны) по две латинские буквы, так
что английская строка занимает столько же байт, сколько японская. Русский
перевод делает то же с кириллицей (`lib/textcodec.is_narrow`): шрифт —
X11 misc-fixed 6x13, в котором есть кириллица. Нужно около 2100 пар букв
при 2789 свободных ячейках, так что каждая пара получает свою ячейку и
ничего не выводится широкими запасными буквами.

Строки, которые длиннее японского оригинала, игра читает из отдельного
блока в верхней памяти (`ps1/tools/repoint.py`), как и в английской
версии; переносы строк расставляются по ширине окна (18 клеток, 14 в
терминале Гауди).

Перевод лежит прямо в `ps1/translation/*.json` в полях `en`/`long` (имена
полей остались от английской версии); исходный английский текст сохранён
рядом в `en_src`/`long_src`. Формат файлов описан в
[ps1/README.md](ps1/README.md), внутреннее устройство игры и патча — в
[docs/ps1.md](docs/ps1.md) (на английском).

## Сборка из исходников

Кратко (подробнее — [BUILDING.md](BUILDING.md)):

```sh
pip install -r requirements.txt
python3 build.py discs /путь/к/образам     # PS1 обязателен, Saturn — для картинки из раздевалки
python3 build.py doctor
python3 build.py ps1 --release
```

Образ — `patched/Snatcher (Japan).bin`, архив с патчем — `release/`.

## Правка перевода

- Одна строка: поправить `en` (или `long`, если он есть) в
  `ps1/translation/ISZ_<сцена>.json`, либо `en` в `subs_<сцена>.json`, затем
  `sh ru/build_ru.sh` — он заново распределит пары букв по ячейкам шрифта
  и соберёт образ.
- Пакетная работа: `python3 ru/rutools.py export` выгружает задания с
  японским текстом в `work/ru/tasks` (в git не попадают), перевод кладётся в
  `work/ru/out/<сцена>/*.json`, проверка — `python3 ru/rutools.py validate --all`,
  унификация меню и терминов — `python3 ru/unify.py --write`, затем
  `sh ru/build_ru.sh`.
- Проверка в эмуляторе без участия человека: `lib/emurun.py` (libretro-ядро,
  скриншоты по кадрам).
