Snatcher - русский перевод (PlayStation, uncensored), версия {version}

Русский перевод японской PlayStation-версии Snatcher (Konami, 1996,
SLPS-00154) на основе английского фанперевода pepa (v1.5.1), с картинками,
которые PlayStation-версия цензурирует. Перевод сделан с помощью ИИ.

Нужен ваш собственный образ Snatcher (Japan) в формате redump BIN/CUE:

  Snatcher (Japan).bin
  Size   573702192
  SHA1   {src_sha1}

Наложение патча (xdelta3, Delta Patcher, MultiPatch или другая оболочка xdelta):

  xdelta3 -d -s "Snatcher (Japan).bin" "{name}.xdelta" "{name}.bin"

Рядом с полученным .bin положите "{name}.cue" из этого архива.
Новый образ больше исходного - так и должно быть.

Результат:

  {name}.bin
  SHA1   {out_sha1}

Картинка из раздевалки (Saturn-оригинал): {lisa}

с образом диска. Snatcher (c) Konami.
