# Snatcher — русский перевод (PlayStation)

Русский перевод *Snatcher* (PlayStation, SLPS-00154) на основе английского
фанперевода pepa (v1.5.1) со сверкой по японскому оригиналу. Версия перевода —
в `ru/VERSION`.

## Что переведено

- Весь сценарий: 39 сцен, диалоги, описания, база данных Гауди, звонки по
  видеофону, меню действий и предметов, отладочное меню.
- Субтитры к озвученным сценам и вступлению (включая надпись, впечатанную в
  чертёж снатчера).
- Таблички с именами говорящих.
- Картинки с текстом: 13 страниц записок Гибсона, записка «Обыщи дом!»,
  карточки видеофона, шуточные картинки телефонного справочника, красный
  дисклеймер после New Game и его копия во вступительном ролике.
- Загрузочные экраны: карточка перевода и предупреждение об ИИ-переводе.

Остаются латиницей: клавиатура и всё, что на ней набирается (имена для поиска
в базе Гауди, пароль Наполеона и другие загадки с вводом текста), оригинальные
английские надписи Konami («NOW LOADING», «50 years later», посвящение,
OPTION MENU), титры вступления.

## Как устроено

Игра хранит текст двухбайтовыми кодами символов шрифта. Английский перевод
рисует в неиспользуемых ячейках шрифта по две латинские буквы; русский
делает то же с кириллицей (`lib/textcodec.is_narrow`), поэтому строка
занимает столько же места, сколько английская. Пар букв нужно около 2100 при
2789 свободных ячейках. Строки длиннее японского оригинала уходят в
«длинный» блок в верхней памяти (`ps1/tools/repoint.py`), как в английской
версии.

Перевод хранится прямо в `ps1/translation/*.json` (поля `en`/`long`; исходный
английский сохранён рядом в `en_src`/`long_src`). Термины и правила —
`ru/GLOSSARY.md`.

## Сборка

Нужен свой образ *Snatcher (Japan)* для PlayStation в формате redump
(BIN/CUE), см. `BUILDING.md`.

```sh
pip install -r requirements.txt
python3 build.py discs /путь/к/образу
sh ru/build_ru.sh            # или: sh ru/build_ru.sh --no-fmv (без ролика, быстрее)
```

Готовый образ — `patched/Snatcher (Japan).bin` + `.cue`.

`ru/build_ru.sh` сливает перевод из `work/ru/out` (если есть), заново
распределяет пары букв по ячейкам шрифта и запускает обычную сборку PS1.

## Правка перевода

- Поправить строку: отредактировать `en`/`long` в `ps1/translation/ISZ_<S>.json`
  или `en` в `subs_<S>.json`, затем `sh ru/build_ru.sh`.
- Рабочий цикл переводчиков: `python3 ru/rutools.py export` (задания с японским
  текстом в `work/ru/tasks`, в git не попадают), перевод в
  `work/ru/out/<S>/*.json`, проверка `python3 ru/rutools.py validate --all`,
  унификация терминов и меню `python3 ru/unify.py --write`.
